# AUDIO DESIGN — музыка и звуки

> APPROVED: ~5 музыкальных тем, музыка генерируется нейросетью и отбирается автором; звуки — из бесплатных
> библиотек с открытой лицензией; озвучки нет; «хихик» — текстом со звуком-искоркой.
> Конкретные списки — **[PROPOSED]**. Условия использования сервиса генерации музыки — проверить до выбора (OPEN).
> Песня «Династия» (madk1d) в игре **не звучит**, только упоминается.

## 1. Музыка

| ID | Где | Настроение | Длина / цикл |
|---|---|---|---|
| `mus_menu` | Главное меню | Тихая зимняя, музыкальная шкатулка | 60–90 с, бесшовный цикл |
| `mus_world1` | L01–L03 | Зимний синтвейв / чиптюн, уютно-таинственно | 90–120 с, цикл |
| `mus_world2` | L04–L05 | Свинг / биг-бэнд 1930-х, бодро, с юмором | 90–120 с, цикл |
| `mus_world3` | L06–L07 | Драматичная оркестровка в духе графического романа, к L07 — мягче | 90–120 с, цикл |
| `mus_finale` | L08, открытка, титры | Тёплая тема с курантами | 120–180 с |

**Правила воспроизведения:**
- Смена трека — кроссфейд 1,5 с.
- Во время перехода «перерисовка кистью» — свип-звук `sfx_transition`, музыка нового мира начинается с конца перехода.
- В L07 после примирения `mus_world3` затухает и включается `mus_finale` (вступление) **[PROPOSED]**.
- Пауза — музыка приглушается до 30%.

## 3. Технические требования

- Формат: `.ogg` (основной) + `.m4a` (запасной для Safari/iOS) **[PROPOSED]**. Музыка 128 кбит/с, звуки 96 кбит/с, моно для звуков.
- Громкость нормализовать: музыка ≈ −16 LUFS, звуки ≈ −12 LUFS (пики).
- Звуки — бесплатные библиотеки с открытой лицензией (CC0 предпочтительно). Для каждого файла записать источник
  и лицензию в `public/assets/audio/CREDITS.md`.
- Первый звук — только после первого взаимодействия пользователя (ограничение браузеров).
