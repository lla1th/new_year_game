# UI / UX — интерфейс

> APPROVED, кроме **[PROPOSED]**. Интерфейс реализуется на Vue 3 поверх canvas Phaser (`TECHNICAL_SPECIFICATION.md`).

## 1. Экраны

```
Главное меню ─┬─ Начать ──────────────► L01
              ├─ Продолжить (если есть сохранение) ► последняя контрольная точка
              ├─ Выбор уровня (после GAME_COMPLETED) ► L01…L08
              └─ Настройки
Игра ── Пауза (Esc / ⚙) ─┬─ Продолжить
                          ├─ Настройки
                          └─ В главное меню
Финал: Открытка → Титры → Сцена после титров → Главное меню
```

### Главное меню
- Фон: пиксельное окно квартиры со снегом (анимированный падающий снег).
- Название «Операция: Новый год».
- Кнопки: «Начать», «Продолжить» (только при наличии сохранения), «Выбор уровня» (только после прохождения), «Настройки».
- «Начать» при существующем сохранении → подтверждение «Начать заново? Прогресс сбросится» **[PROPOSED]**.

## 2. Игровой HUD

```
┌──────────────────────────────────────────────┐
│ [◔◔◔] 0/3                [🐕][🔍][⚙]          │
│                                              │
│              игровая сцена                   │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ [портрет] Имя: текст реплики…            │ │  ← диалог (когда идёт)
│ └──────────────────────────────────────────┘ │
│ [ □ ][ □ ][ □ ][ □ ][ □ ][ □ ]               │
└──────────────────────────────────────────────┘
```

| Элемент | Позиция | Поведение |
|---|---|---|
| Индикатор Часов | Слева сверху | 3 гнезда; деталь появляется с анимацией «влёта»; в L08 детали перетаскиваются отсюда |
| Кнопка-шпиц (подсказка) | Справа сверху | Скрыта до `L01_SPITZ_FREED`; нажатие → реплика-подсказка в окне диалога |
| Кнопка 🔍 | Справа сверху | Подсветка хотспотов на 2 с |
| Кнопка ⚙ | Справа сверху | Пауза |
| Инвентарь | Снизу по центру | 6 слотов; во время диалога затемнён и неактивен |
| Окно диалога | Снизу, над инвентарём | Портрет слева, имя, текст; варианты ответа — кнопками в окне |

**Размеры** (в координатах 1920×1080) **[PROPOSED]**: слот инвентаря 120×120 с отступом 16; кнопки HUD 96×96;
окно диалога 1400×220. Минимальная зона касания на телефоне — 44×44 CSS-пикселя.

## 3. Приближённые экраны головоломок

- Открываются зумом камеры к объекту (0,5 с), затем поверх сцены — экран головоломки с затемнённым фоном.
- Крестик в правом верхнем углу (или клик по затемнённому фону) закрывает экран без потери прогресса головоломки
  (состояние головоломки хранится до решения) **[PROPOSED]**.
- Инвентарь остаётся видимым, если головоломка принимает предметы (P-02), иначе скрыт.
- Кнопки «Сброс» / «Перемешать заново» — внизу экрана головоломки.

## 4. Диалоги

- Печать по буквам: **[PROPOSED]** 40 символов/с при «нормальной» скорости (30 / 40 / 60 — медленно / нормально / быстро).
- Клик во время печати → строка целиком. Клик после → следующая реплика.
- Индикатор «дальше» (мигающая стрелка) в правом нижнем углу окна.
- Варианты ответа: до 3 кнопок; выбор → реплика Ксюши → общая следующая реплика.
- Реплика «Хихик» сопровождается коротким звуком-искоркой и позой `hihik`.

## 5. Настройки

| Настройка | Значения | По умолчанию |
|---|---|---|
| Громкость музыки | 0–100 | 70 |
| Громкость звуков | 0–100 | 80 |
| Скорость текста | Медленно / Нормально / Быстро | Нормально |
| Полный экран | Вкл / Выкл | Выкл |

Язык — только русский. Настройки сохраняются отдельно от прогресса и не сбрасываются при «Начать заново».

## 6. Телефон и планшет

- Только горизонтальная ориентация. В вертикальной — экран-заглушка «Поверните телефон» с анимацией телефона.
- Масштабирование: игра вписывается в экран с сохранением 16:9, свободные поля — тёмный фон.
- Долгий тап = осмотр. Контуров при наведении нет.
- Перетаскивание предметов пальцем: иконка поднимается над пальцем на 60 px, чтобы её было видно **[PROPOSED]**.
- Кнопка «Полный экран» на телефоне скрывается там, где браузер её не поддерживает.
- Первый звук запускается только после первого касания (ограничение браузеров на автозапуск звука).

## 7. Обратная связь

| Событие | Визуально | Звук |
|---|---|---|
| Предмет подобран | Иконка «влетает» в слот | `sfx_pickup` |
| Предмет не подошёл | Иконка возвращается в слот | `sfx_nope` |
| Головоломка решена | Вспышка, конфетти в стиле мира | `sfx_solve` |
| Деталь Часов получена | Деталь летит в индикатор | `sfx_part` |
| Контрольная точка | Иконка снежинки в углу на 1,5 с **[PROPOSED]** | — |

## 8. Доступность

- Все головоломки решаемы без звука (колокола подсвечиваются, у гирлянды есть надписи цветов при осмотре).
- Цвета лампочек дополнительно различаются формой блика **[PROPOSED]** — для различения без цвета.
- Текст не меньше 28 px в координатах 1920×1080.
