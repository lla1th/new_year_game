# Промпты: визуал L01 «31 декабря, 23:59» (мир 1, пиксель-арт)

> Статус: **PROPOSED** — черновик для автора, правь свободно. Источник: `ART_BIBLE.md`, `SCRIPT.md` §4, карты
> `public/assets/maps/L01.json`, `L01_workshop.json`. Промпты на английском — нейросети понимают его лучше.
> Фото реальных людей прикладывать к нейросети только локально, в репозиторий не добавлять (`ART_BIBLE.md`).

## 0. Как пользоваться

1. **Сначала листы персонажей (§2)** → выбрать удачные → дальше каждую генерацию делать с ними как с референсом
   (character / style reference в выбранном сервисе).
2. **Фоны (§4)** генерировать с картинкой-схемой из `docs/prompts/layouts/` как наброском композиции
   (image-to-image / structure reference). Объекты должны попасть в оранжевые рамки — там игра ждёт клики.
3. **Постобработка пиксель-арта** (обязательно, иначе пиксели «плавают»):
   уменьшить до натива **без сглаживания** (nearest neighbor) → ограничить палитру (16–32 цвета, §1) →
   подчистить в Aseprite: одиночные пиксели, «грязные» края, контур.
4. Натив: фон **480×270**; Ксюша ≈ **48–56 px** ростом; в игре всё ×4. Ноги персонажа — нижний край кадра по центру.
5. Направление персонажей — **только вправо** (вниз-вправо / вверх-вправо); влево игра отражает сама.

### Общий префикс мира 1 (добавлять в начало каждого промпта)
```
pixel art, 16-bit era game sprite style, cinematic lighting, snowy winter night, limited palette,
crisp hard pixels, no anti-aliasing, no dithering noise, clean readable silhouettes
```

### Общий негатив (если сервис поддерживает negative prompt)
```
blurry, anti-aliasing, smooth gradients, photorealistic, 3d render, text, watermark, signature, logo,
jpeg artifacts, extra limbs, extra fingers, cropped feet, mixed pixel sizes, noisy dithering
```
