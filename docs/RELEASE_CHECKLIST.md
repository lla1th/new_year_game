## Не пройдено / ждёт

1. **Тестеры** (1–2 человека, не Ксюша): время прохождения 30–45 мин и места, где застревали → правка подсказок в `ru.json`.
2. **Реальные телефоны автора**: Android Chrome и iOS Safari — пройти L01–L02, сообщить проблемы.
3. **Firefox и Safari (WebKit)**: `E2E_ALL_BROWSERS=1 npm run e2e` на машине, где они установлены.
4. **Публикация на GitHub Pages**: только после решения автора по вопросу T1 (приватность).
5. **Графика и звук** автора (M4): подключение, подгонка разметки Tiled, `CREDITS.md`, повторный замер загрузки и FPS.
6. **Финальный текст**: заменить заглушки `l08.card.text`, `l08.card.gift` в `public/data/texts/ru.json`, при желании —
   имена в `public/data/characters.json` (шпиц, кошечка, улитка); после правки — повторная публикация.
