# ACCEPTANCE CRITERIA — критерии готовности

> Критерии для отдельных задач — в `LEVEL_DESIGN.md` (TASK-xxx), для головоломок — сценарии тестирования
> в `PUZZLE_SPECIFICATIONS.md`. Здесь — критерии готовности систем и игры целиком.

## 1. Игра целиком

- [ ] Игру можно пройти от «Начать» до сцены после титров без ошибок в консоли браузера.
- [ ] Полное прохождение занимает 30–45 минут у человека, который играет впервые (проверка на 1–2 тестерах, не на Ксюше).
- [ ] В игре нельзя застрять: у каждой цели есть 3 ступени подсказки, тупиковые головоломки имеют «Сброс», P-08 — автосборку.
- [ ] Ни одна ошибка игрока не приводит к проигрышу или потере прогресса.
- [ ] Работает в актуальных Chrome, Firefox, Safari (macOS) на компьютере и в Chrome (Android), Safari (iOS) на телефоне.
- [ ] На телефоне в вертикальной ориентации показывается «Поверните телефон».
- [ ] Игра открывается по ссылке GitHub Pages.

## 2. Системы

### Перемещение
- [ ] Клик по полу → Ксюша идёт в точку по пути внутри проходимой области, не проходит сквозь мебель.
- [ ] Клик вне области → идёт к ближайшей проходимой точке.
- [ ] Ксюша поворачивается по направлению движения (4 диагонали) и покачивается при ходьбе.
- [ ] Ксюша корректно заходит «за» объекты переднего плана.
- [ ] Шпиц следует за Ксюшей с L01 (после освобождения) до L08.

### Взаимодействие
- [ ] Наведение мыши на хотспот показывает контур и нужный курсор.
- [ ] ПКМ / долгий тап → текст осмотра.
- [ ] Кнопка 🔍 / Пробел подсвечивает все активные хотспоты на 2 с.
- [ ] Каждый предмет можно получить ровно один раз.

### Инвентарь
- [ ] 6 слотов, предметы переносятся между уровнями.
- [ ] Перетаскивание работает мышью и пальцем.
- [ ] Неверный предмет → случайная фраза из набора, предмет возвращается.
- [ ] Комбинирование работает только для ленточки и медали.

### Диалоги
- [ ] Текст печатается по буквам с выбранной скоростью; клик показывает строку целиком / переходит дальше.
- [ ] Все тексты берутся из `public/data/texts/ru.json`; изменение файла меняет текст в игре без правки кода.
- [ ] Имена шпица/кошечки/улитки меняются в одном месте (`characters.json`).

### Подсказки
- [ ] Кнопка-шпиц выдаёт ступени 1 → 2 → 3, затем повторяет 3-ю.
- [ ] Через 90 с без прогресса шпиц сам произносит подсказку.
- [ ] Подсказка соответствует текущей цели (по флагам).

### Сохранение
- [ ] Автосохранение в начале каждого уровня и после каждой головоломки.
- [ ] После перезагрузки страницы «Продолжить» возвращает к последней точке с тем же инвентарём, флагами и деталями.
- [ ] Повреждённое сохранение не ломает игру («Продолжить» скрыт).
- [ ] После прохождения доступен выбор уровня.

### Переходы
- [ ] «Перерисовка кистью» проигрывается в конце L03, L05 и при входе в L08, длится 2–3 с.
- [ ] Иконки предметов сохраняют стиль родного мира.

### Звук
- [ ] У каждого мира своя музыкальная тема, смена — кроссфейдом.
- [ ] Регуляторы громкости музыки и звуков работают раздельно и сохраняются.
- [ ] Звук не стартует до первого взаимодействия.
- [ ] Для каждого звука указан источник и лицензия в `CREDITS.md`.

### Графика
- [ ] Пиксельный мир — чёткие пиксели без размытия.
- [ ] Якоря Ксюши (рыжие волосы, розовая шапка, чокер) видны во всех трёх стилях.
- [ ] Фото реальных людей отсутствуют в репозитории и билде.

### Производительность
- [ ] ≥ 30 кадров/с на среднем телефоне, 60 на компьютере.
- [ ] Билд ≤ 60 МБ, загрузка уровня ≤ 5 с на 4G **[PROPOSED]**.

## 3. Головоломки

- [ ] Для P-02…P-08 все сценарии тестирования из `PUZZLE_SPECIFICATIONS.md` покрыты юнит-тестами логики и проходят.
- [ ] Начальные раскладки P-04 и P-05 не решены сразу, эталонные решения засчитываются.
- [ ] 100 перемешиваний P-08 подряд решаемы и не собраны изначально.

## 4. Финал

- [ ] Текст поздравления и строка о подарке берутся из файла данных.
- [ ] Титры содержат «Сделано с любовью для Ксюши» и всех персонажей.
- [ ] Сцена после титров показывает квартиру со спящими шпицем и кошечкой и улиткой в террариуме, реплика «Хихик».
