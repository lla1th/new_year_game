# INTERACTION SYSTEM — объекты, предметы, флаги

> APPROVED, кроме **[PROPOSED]**. Это единый справочник ID: все остальные документы ссылаются на него.

## 1. Хотспоты (интерактивные объекты)

Каждый объект сцены, с которым можно взаимодействовать, — **хотспот**, размеченный в Tiled (объектный слой `hotspots`).

| Свойство | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный в уровне, напр. `sofa`, `fridge` |
| форма | polygon / rect | Область клика |
| `approachX`, `approachY` | number | Точка, куда подходит Ксюша (должна быть в проходимой области) |
| `facing` | `dr` / `dl` / `ur` / `ul` | Куда повернуться при действии |
| `cursor` | `hand` / `eye` / `gear` / `talk` / `exit` | Курсор при наведении |
| `enabledIf` | string | Флаг, при котором хотспот активен (пусто — всегда) |
| `hiddenIf` | string | Флаг, при котором хотспот скрыт |

**Состояния хотспота:** `hidden` → `idle` → `hover` → `active` (идёт действие) → `idle` / `done`.
- `hidden`: не рисуется, не кликается.
- `idle`: виден, кликается, без контура.
- `hover`: светлый контур + свой курсор (только мышь).
- `active`: на время действия Ксюши, повторные клики игнорируются.
- `done`: взаимодействие исчерпано; остаётся только осмотр (если есть текст осмотра).

## 2. Типы взаимодействий

| Действие | Как вызывается | Что происходит |
|---|---|---|
| **Осмотр** | ПКМ / долгий тап | Ксюша (или шпиц) произносит текст `<level>.<hotspot>.inspect`. Ходить к объекту не нужно. |
| **Использование** | ЛКМ / тап | Ксюша подходит к `approach`, поворачивается, поза `use`, затем выполняется скрипт хотспота |
| **Разговор** | ЛКМ / тап по персонажу | Подходит, открывается диалог |
| **Предмет на объект** | Перетаскивание из инвентаря | Подходит, если у пары (предмет, хотспот) есть реакция — выполняет её; иначе `common.wrongItem.*` |
| **Выход / переход** | ЛКМ по хотспоту с `cursor = exit` | Подходит, затемнение 0,4 с, следующий экран |
| **Приближённый экран** | ЛКМ по хотспоту головоломки | Плавный зум камеры к объекту (0,5 с) и открытие экрана головоломки поверх сцены |

## 3. Как игрок понимает, что объект интерактивный

- Мышь: при наведении — светлый контур объекта и смена курсора.
- Телефон: контуров нет; первый тап по объекту коротко подсвечивает его и сразу выполняет действие **[PROPOSED]**.
- Кнопка 🔍 / Пробел: на 2 с подсвечивает контуром все хотспоты в состоянии `idle`.

## 4. Предметы

| ID | Название | Где берётся | Где используется | Расходуется |
|---|---|---|---|---|
| `ITEM_MANDARIN` | Мандарин | L01, стол | L01 диван (неверно), L02 снеговик (необяз.) | Только на снеговике; если не использован — удаляется при переходе в L03 |
| `ITEM_SAUSAGE` | Колбаса | L01, холодильник | L01 диван | Да |
| `ITEM_BULB_GREEN` | Зелёная лампочка | L02, соседняя палатка | P-02 | Да (при успехе P-02) |
| `ITEM_BULB_GOLD` | Золотая лампочка | L02, нос снеговика | P-02 | Да |
| `ITEM_BULB_BLUE` | Синяя лампочка | L02, под каруселью | P-02 | Да |
| `ITEM_GATE_KEY` | Ключ от ворот | L02, Ника | L02 ворота | Да |
| `ITEM_COCOA` | Кружка какао | L02, Ника | L03 сова | Да |
| `ITEM_CANDY_CANE` | Леденцовая трость | L04, банка со сладостями | L04 пряничный человечек | Да |
| `ITEM_VALVE` | Вентиль | L04, пряничный человечек | L04 бак с глазурью | Да |
| `ITEM_MITTENS` | Варежки | L04, Леха | L05 вход на склад (проверка наличия) | Удаляются в конце L05 |
| `ITEM_RIBBON` | Ленточка | L07, Ника | P-07 | Да (комбинирование) |
| `ITEM_GINGER_MEDAL` | Пряничная медаль | L07, Леха | P-07 | Да (комбинирование) |
| `ITEM_KEEPER_MEDAL` | Медаль Хранительницы | L07, комбинирование | L07 кошечка | Да |

Детали Часов (`PART_SPRING`, `PART_GEAR`, `PART_HANDS`) — не предметы инвентаря, а состояние индикатора Часов.

**Иконка предмета** рисуется в стиле мира, где он найден, 128×128 PNG.

**Повторное взятие:** у каждого предмета источник срабатывает один раз; после этого хотспот-источник переходит в
`done` (или `hidden`, если объект физически исчез).

## 5. Реакции на неверные действия

- Неверный предмет: случайная фраза из `common.wrongItem.1…N` (N ≥ 5), без повтора предыдущей **[PROPOSED]**.
  Черновик: «Не, не то», «Гениально, но нет», «Хихик, нет», «Это так не работает», «Шпиц смотрит на меня с осуждением».
- Неверная пара для комбинирования: `common.cantCombine` — «Не сочетается».
- Клик по объекту без предусмотренного действия: текст осмотра.

## 6. Флаги состояния

Флаги — булевы значения в сохранении. Имена: `L<NN>_<СОБЫТИЕ>`.

| Флаг | Ставится когда |
|---|---|
| `L01_SPITZ_FREED` | Колбаса использована на диване |
| `L01_PORTAL_OPEN` | Закончился диалог «Знакомство» |
| `L01_PORTAL_ENTERED` | Клик по светящемуся террариуму (переход в L02); завершает цель «войти в портал» для подсказок |
| `L02_SNOWMAN_SAD` | Взята золотая лампочка |
| `L02_SNOWMAN_HAPPY` | Мандарин отдан снеговику (необяз.) |
| `L02_CAROUSEL_SPUN` | Клик по карусели, лампочка выкатилась |
| `L02_BULB_GREEN_TAKEN` / `L02_BULB_BLUE_TAKEN` | Взята зелёная / синяя лампочка (источник срабатывает один раз, даже когда лампочка уже в гирлянде) |
| `L02_GARLAND_DONE` | P-02 решена, Ника оттаяла |
| `L02_GATE_OPEN` | Ключ использован на воротах |

| `L04_VALVE_TAKEN` | Человечек отдал вентиль |
| `L04_VALVE_INSTALLED` | Вентиль на баке |
| `L04_PIPES_DONE` | P-04 решена |
| `L05_ENTERED` | Ксюша вошла на склад с варежками |

## 8. Реакции в диалогах (портреты по настроению)

У реплики можно указать **реакцию** (`mood`) — тогда в окне диалога показывается портрет этой реакции. Допустимые id: `happy`, `sad`, `angry`, `surprised`, `scared`, `thinking`, `smug`, `embarrassed` (список — `MOOD_IDS` в `src/game/data/types.ts`).

**Где указывать реакцию** (всё необязательно; без `mood` — обычный портрет):

| Место | Пример |
|---|---|
| Реплика в `public/data/dialogs.json` | `{ "speaker": "spitz", "key": "…", "mood": "happy" }` |
| Вариант ответа (реакция Ксюши, когда она его говорит) | `"choices": [{ "key": "…", "mood": "surprised" }]` |
| Ответ на вариант | `"reply": { "speaker": "spitz", "key": "…", "mood": "angry" }` |
| Шаг скрипта уровня | `{ say: 'spitz', key: 'l02.spitz.crossout', mood: 'smug' }` |

**Какие файлы подставляются** — `public/data/characters.json`, раздел `moods`: `персонаж → реакция → стиль мира (w1/w2/w3/fin) → путь относительно assets/`:

```json
"moods": { "spitz": { "happy": { "w1": "img/portraits/spitz_happy_w1.png" } } }
```

Порядок выбора: портрет реакции в стиле текущего мира → обычный портрет (`portraits`) → цветная заглушка. Поэтому реакцию можно проставлять в диалогах заранее, а арт добавлять позже. Неизвестный id реакции ловит тест `tests/data/portraits.test.ts`.
