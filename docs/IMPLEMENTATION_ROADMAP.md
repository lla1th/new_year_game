## M0. Каркас (23.11 – 26.11)

**Задачи:**
1. Проект из шаблона Vue + TypeScript (`npm create @phaserjs/game@latest`), Phaser 4, Vitest. Сверить шаблон и API через Context7.
2. Структура папок по `TECHNICAL_SPECIFICATION.md` §3.
3. Загрузка JSON из Tiled: фон, слои `walkable`, `blockers`, `hotspots`, `points`.
4. Растеризация проходимой области, A*, ходьба Ксюши-заглушки с покачиванием.
5. Масштабирование 1920×1080, отладочный режим `?debug=1` (полигоны).
6. GitHub Actions → GitHub Pages (после решения T1 можно временно не публиковать).

**Зависимости:** нет.
**Готово, когда:** на тестовой карте Ксюша-заглушка ходит по клику в обход препятствий; отладка показывает полигоны.

## M1. Ядро систем (27.11 – 03.12)

**Задачи:**
1. GameState + SaveService (формат из техспецификации §9).
2. EventBus, Vue-HUD: инвентарь, кнопки, индикатор Часов.
3. Хотспоты: наведение, курсоры, осмотр, использование, перетаскивание предмета на хотспот.
4. Диалоги (печать, варианты), загрузка `ru.json`, `characters.json`, `items.json`, подстановка имён.
5. Скрипты уровней (шаги `say`, `giveItem`, `setFlag`, …).
6. Подсказки: кнопка, автоподсказка 90 с, цели по флагам.
7. Приближённые экраны (зум + оверлей), заставка.
8. **L01 целиком** на заглушках + P-01.
9. Главное меню, пауза, настройки.

**Зависимости:** M0.
**Готово, когда:** L01 проходится от заставки до портала; сохранение и «Продолжить» работают; тексты меняются через `ru.json`.
