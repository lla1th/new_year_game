# R3 «L02: Ярмарка» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** L02 по `docs/SCRIPT.md` §5: 5 экранов, обезьянка (S-02a, вариант A), цепочка «кошечка → ключ склада → сарай», P-02 «Генератор» (3 лампочки по цветам, насос, бензин, шнур), оживление ярмарки, тир S-02b, финальный диалог с Никой, какао, телепортатор → L03.

**Architecture:** Всё data-driven, как в R2: `L02.ts` (скрипт), карты из генератора (`tools/maps/L02_*.ts`), тексты из `SCRIPT.md` → `texts:build`, чистая логика головоломок в `src/puzzles/logic/` (`generator.ts`, `gallery.ts`), тонкие Phaser-экраны (`GeneratorScreen`, `GalleryScreen`). P-02 сохраняет id `P-02`, но вместо «Гирлянды» это «Генератор»; старая логика и экран удаляются в конце этапа (Task 8).

**Tech Stack:** TypeScript, Vitest, Phaser 4, Vue 3.

**Spec:** `docs/SCRIPT.md` §5.1–§5.7, §12а (разговоры Ники уже в данных R1); планы R0–R2.

**Предусловие:** R0–R2 выполнены, `npm test` зелёный.

## Global Constraints

- Правила `CLAUDE.md`; реплик в коде нет; тексты — `SCRIPT.md` → `npm run texts:build`; пустые поля автора не блокируют разработку.
- Инвентарь — 6 слотов. Пик L02: мандарин + 3 лампочки + насос + ключ склада = 6 — **новых предметов в L02 не добавлять**; ключ ворот и фольга существуют не одновременно с этим пиком.
- Состояние головоломки не сохраняется; сохраняются флаги и инвентарь на момент чекпойнта. Чтобы частично вставленные лампочки не пропадали при сохранении, закрытие экрана генератора без полной установки **возвращает** лампочки в инвентарь (Ruling R3-1).
- Неверное действие — без штрафов и тупиков; порядок «лампочки / бензин» произвольный.
- Графика — заглушки; ключи текстур — в `docs/ASSET_REQUIREMENTS.md` (Task 8).
- Старые ID (`ITEM_BULB_GREEN`, `ITEM_BULB_GOLD`, `L02_GARLAND_DONE`, `L02_BULB_GREEN_TAKEN`) удаляются только в Task 8, когда на них никто не ссылается.

## Review Focus

- Любой порядок лампочек/бензина/шнура: шнур без лампочек или без бензина — «Чихнул и затих», без потери предметов. Тест в Task 1.
- Лампочка чужого цвета в гнездо не встаёт и остаётся в инвентаре. Тест в Task 1.
- Пик инвентаря: ни один допустимый порядок действий не требует 7-го слота (тест перебором порядка сбора). Тест в Task 6.
- Ключ склада до `L02_CAT_SCENE_DONE` не берётся; сарай не открывается без ключа. Тест в Task 6.
- Пустая таблица рекордов автора и незаполненные параметры тира не роняют игру: рекорд — запасное значение, имена — `—`. Тест в Task 2.
- После выбора имени шпица в таблице вместо «Шпиц-хранитель» стоит его имя; без выбора — «Шпиц-хранитель». Тест в Task 2.
- Кошачья сцена не повторяется после загрузки сохранения (флаг `L02_CAT_SCENE_DONE`). Тест в Task 6.
