# M1 «Ядро систем» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Все общие системы игры (состояние, сохранения, события, тексты, скрипты, подсказки, хотспоты, инвентарь, диалоги, меню) и полностью проходимый уровень L01 на заглушках.

**Architecture:** Чистая логика (GameStateModel, SaveService, TextBank, ScriptRunner, HintSystem, хит-тест) — TS-модули с тестами. Vue рисует HUD/инвентарь/диалоги/меню и общается с Phaser через `bus`. Уровень описан декларативным `LevelScript`, тексты — ключами в `ru.json`.

**Tech Stack:** Phaser 4, Vue 3, TypeScript, Vitest.

**Spec:** `docs/GAMEPLAY.md`, `docs/INTERACTION_SYSTEM.md`, `docs/UI_UX.md`, `docs/LEVEL_DESIGN.md` (L01, TASK-001/002), `docs/PUZZLE_SPECIFICATIONS.md` (P-01), `docs/STORY.md` (L01), `docs/TECHNICAL_SPECIFICATION.md` §2, 7–9; контракты `00-contracts.md` §4–8.

**Предусловие:** этап M0 выполнен (NavGrid, parseTiledMap, LevelScene.walkTo, ensureTexture).

## Global Constraints

- Правила `CLAUDE.md`: API Phaser/Vue — только после сверки через Context7.
- Весь видимый игроку текст — только через `TextBank.t(key)`; в коде нет русских строк.
- Инвентарь — 6 слотов; детали Часов — не в инвентаре, а в индикаторе.
- Скорость печати текста: 30 / 40 / 60 символов/с (медленно / нормально / быстро).
- Автоподсказка — 90 с без прогресса. Долгий тап — ≥ 500 мс.
- Ошибки игрока никогда не наказываются.
- Сохранение — `localStorage`, ключи `onye-save-v1`, `onye-settings-v1`; запись в начале уровня и после каждой головоломки.
- Коммиты на русском, Conventional Commits, после каждой задачи.

## Review Focus

- Перетаскивание предмета на пустое место сцены (не на хотспот) — предмет возвращается в слот без реплики и без ошибки в консоли. Тест в Task 5 (`hitTestHotspots` → `null`).
- Двойной клик по хотспоту, пока Ксюша идёт к нему или выполняет действие, — действие выполняется один раз. Проверка в Task 5, шаг 5 (состояние `active` игнорирует клики).
- Перезагрузка страницы посреди диалога — «Продолжить» возвращает к началу уровня (контрольной точке), а не ломает игру. Тест в Task 1 + проверка в Task 8.
- Ключ текста отсутствует в `ru.json` — показывается `⟨ключ⟩`, игра продолжается. Тест в Task 2.
- Клик по кнопке подсказки во время диалога — игнорируется (не накладывается второе окно). Проверка в Task 6.
