# M0 «Каркас» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Запускаемый проект Vue 3 + Phaser 4 + TypeScript, в котором сцена грузит разметку Tiled, а Ксюша-заглушка ходит по клику в обход препятствий.

**Architecture:** Vue-приложение монтирует canvas Phaser. Логика (геометрия, разбор Tiled, поиск пути) — чистые TS-модули с юнит-тестами Vitest. Phaser-сцена `LevelScene` только рисует и передаёт клики.

**Tech Stack:** Phaser 4, Vue 3, TypeScript, Vite, Vitest, Tiled (JSON).

**Spec:** `docs/TECHNICAL_SPECIFICATION.md` (§1–6, 10–13), `docs/GAMEPLAY.md` §3, `docs/INTERACTION_SYSTEM.md` §1, контракты `docs/superpowers/plans/00-contracts.md` §1–3, §10.

## Global Constraints

- Правила `CLAUDE.md` обязательны: перед любым вызовом API Phaser/Vue/Vite/Vitest сверяться с документацией через Context7; при расхождении с планом — остановиться и спросить.
- Phaser **4** (не 3). Vue 3. TypeScript `strict: true`.
- Логическое разрешение 1920×1080, масштаб «вписать с сохранением пропорций».
- Никаких внешних библиотек поиска пути и состояния — свой код.
- Никакого русского текста в коде, кроме отладочных сообщений (тексты появятся в M1).
- Коммиты на русском в формате Conventional Commits, после каждой задачи.
- Фото реальных людей в репозиторий не добавлять.

## Review Focus

- Клик по точке вне проходимой области (за стеной, в мебели) — Ксюша идёт к ближайшей проходимой точке, а не стоит и не проходит сквозь мебель. Тест в Task 3.
- Клик во время ходьбы — новая цель, старый путь отменяется без рывков. Проверка в Task 4, шаг 5.
- Полигон Tiled с координатами относительно объекта (`x`,`y` + `polygon`) — точки должны переводиться в абсолютные. Тест в Task 2.
- Окно браузера с другим соотношением сторон (узкое, широкое) — игра вписана, клик попадает в правильную точку сцены. Проверка в Task 4, шаг 6.
- Отсутствующая картинка фона — сцена не падает, рисуется заглушка. Тест-проверка в Task 4.

- [ ] **Step 1: Тесты** (на геометрии фикстуры: walkable 100..1800 × 500..1000, blocker 800..1000 × 600..800):

```ts
const g = new NavGrid(walkable, blockers);
expect(g.isWalkable({x:300,y:800})).toBe(true);
expect(g.isWalkable({x:900,y:700})).toBe(false);                    // внутри blocker
expect(g.isWalkable({x:50,y:800})).toBe(false);                     // вне walkable
const path = g.findPath({x:300,y:700}, {x:1500,y:700});
expect(path.at(-1)).toEqual({x:1500,y:700});                        // цель проходима → точно в цель
expect(path.every(p => g.isWalkable(p))).toBe(true);
expect(segmentsAvoid(path, blocker)).toBe(true);                    // хелпер теста: ни один отрезок не пересекает blocker
const toWall = g.findPath({x:300,y:700}, {x:900,y:300});            // цель за пределами
expect(g.isWalkable(toWall.at(-1)!)).toBe(true);
expect(distance(toWall.at(-1)!, {x:900,y:300})).toBeLessThan(260);
expect(g.findPath({x:300,y:700}, {x:300,y:700})).toEqual([]);
```
