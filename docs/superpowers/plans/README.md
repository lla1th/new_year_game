## Как отдать этап исполнителю

Запустить новую сессию Claude Code в этом репозитории с моделью Sonnet 5.5 и отправить:

```
Выполни план docs/superpowers/plans/<файл плана>.md.
Перед началом прочитай CLAUDE.md, docs/superpowers/plans/00-contracts.md и документы спецификации,
перечисленные в шапке плана. Иди по задачам по порядку, отмечай чекбоксы, коммить после каждой задачи.
Если что-то в плане противоречит спецификации или API библиотеки не совпадает с документацией
Context7 — остановись и спроси, не додумывай.
```

После выполнения этапа — проверить «Критерии готовности» в конце плана и пройти игру до текущего места.
