# M3 «Уровни L06–L08 и финал» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Головоломки P-06, P-07, P-08, уровни L06–L08, открытка с поздравлением, титры, сцена после титров и выбор уровня — вся игра проходится от «Начать» до меню на заглушках.

**Architecture:** Как в M2: чистая логика `src/puzzles/logic/*` + экраны-наследники `OverlayScreen` + `LevelScript`. Комбинирование предметов — чистая функция, вызываемая по событию `item:combine`. Финальные экраны (открытка, титры) — Vue-компоненты по событиям `ending:*`.

**Tech Stack:** Phaser 4, Vue 3, TypeScript, Vitest.

**Spec:** `docs/PUZZLE_SPECIFICATIONS.md` (P-06…P-08), `docs/LEVEL_DESIGN.md` (L06–L08, TASK-011…TASK-015), `docs/STORY.md` (L06–L08, титры, сцена после титров), `docs/UI_UX.md` §1, `docs/INTERACTION_SYSTEM.md`; контракты `00-contracts.md`.

**Предусловие:** M2 выполнен (L01–L05 проходятся).

## Global Constraints

- Правила `CLAUDE.md`: API — после сверки через Context7.
- Раскладки — точно из спецификации: P-06 старт `3, 1, 4, 2`; P-08 — поле 3×3, 80 перемешивающих ходов, помощь через **5 минут**, автосборка **250 мс** на ход, анимация хода **120 мс**.
- Комбинируются **только** `ITEM_RIBBON` + `ITEM_GINGER_MEDAL` → `ITEM_KEEPER_MEDAL`.
- Текст поздравления и строка о подарке — только из `ru.json` (`l08.card.text`, `l08.card.gift`), в коде — ни слова поздравления.
- `GAME_COMPLETED` ставится при решении P-08.
- Коммиты на русском, Conventional Commits, после каждой задачи.

## Review Focus

- P-08: «Перемешать заново» не сбрасывает 5-минутный таймер помощи; повторное предложение — ещё через 5 минут после «Сама!». Тест в Task 3.
- P-08: игрок кликает плитки во время автосборки — клики игнорируются, автосборка доходит до конца. Проверка в Task 3, шаг 6.
- P-07: игрок сначала отдаёт кошечке ленточку отдельно — отказ, ленточка остаётся. Тест в Task 5.
- Финал: игрок закрывает вкладку на титрах — при следующем запуске доступен «Выбор уровня» (флаг уже сохранён). Тест в Task 6.
- L08: деталь брошена на чужой силуэт — мягко возвращается в индикатор, без реплики. Тест в Task 6.

### Task 3: P-08 «Пятнашки»

**Files:**
- Create: `src/puzzles/logic/fifteen.ts`, `src/puzzles/screens/FifteenScreen.ts`
- Test: `tests/puzzles/fifteen.test.ts`

**Interfaces:**
- Produces:

```ts
export type Board = number[];                       // длина 9, 0 — пустая клетка; собрано: [1,2,3,4,5,6,7,8,0]
export const SOLVED: Board;
export function isSolved(b: Board): boolean;
export function canMove(b: Board, idx: number): boolean;      // соседняя с пустой по горизонтали/вертикали
export function moveTile(b: Board, idx: number): Board;       // !canMove → тот же массив
export function isSolvable(b: Board): boolean;                // чётность инверсий (3×3)
export function shuffleBoard(rng?: () => number, moves?: number /*80*/): Board;   // без немедленного возврата; если собрано — заново
export function solveBoard(b: Board): number[];               // A* (эвристика — манхэттен), индексы плиток для кликов по очереди
export const HELP_DELAY_MS = 300_000;
export class HelpTimer {                                       // предложение помощи
  constructor(now: () => number);
  shouldOffer(): boolean;       // true, если с открытия/последнего отказа прошло ≥ HELP_DELAY_MS; после true — ждёт ответа
  decline(): void;              // «Сама!» → следующий отсчёт с этого момента
}
```

- [x] **Step 1: Тесты**

```ts
expect(canMove(SOLVED, 7)).toBe(true); expect(canMove(SOLVED, 0)).toBe(false);
expect(moveTile(SOLVED, 7)).toEqual([1,2,3,4,5,6,7,0,8]);
expect(isSolvable([1,2,3,4,5,6,8,7,0])).toBe(false);
for (let i = 0; i < 100; i++) { const b = shuffleBoard(seeded(i)); expect(isSolvable(b)).toBe(true); expect(isSolved(b)).toBe(false); }
const b = shuffleBoard(seeded(42)); expect(isSolved(solveBoard(b).reduce(moveTile, b))).toBe(true);
let t = 0; const h = new HelpTimer(() => t);
t = 299_999; expect(h.shouldOffer()).toBe(false); t = 300_000; expect(h.shouldOffer()).toBe(true);
h.decline(); t = 599_999; expect(h.shouldOffer()).toBe(false); t = 600_000; expect(h.shouldOffer()).toBe(true);
```

- [x] **Step 5: `FifteenScreen`**: картинка-заглушка 900×900 режется на 9 частей (правая нижняя — пусто), превью собранной картинки в углу; клик по соседней плитке — сдвиг за 120 мс; по несоседней — лёгкое покачивание; «Перемешать заново» → `shuffleBoard()` (таймер помощи **не** сбрасывается). `HelpTimer` проверяется раз в секунду; при `true` — реплика шпица `l08.puzzle.help` с кнопками «Да» / «Сама!». «Да» → `solveBoard` и проигрывание по 250 мс на ход, клики игрока на это время отключены.
