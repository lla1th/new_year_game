# M2 «Уровни L02–L05» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Головоломки P-02…P-05 (логика + экраны) и уровни L02–L05, проходимые подряд после L01 на заглушках.

**Architecture:** Логика каждой головоломки — чистый модуль `src/puzzles/logic/<имя>.ts` с неизменяемым состоянием и тестами по сценариям из спецификации. Экран головоломки — наследник `OverlayScreen` (M1), который только рисует состояние и вызывает функции логики. Уровни — `LevelScript` + карты Tiled.

**Tech Stack:** Phaser 4, Vue 3, TypeScript, Vitest.

**Spec:** `docs/PUZZLE_SPECIFICATIONS.md` (P-02…P-05), `docs/LEVEL_DESIGN.md` (L02–L05, TASK-003…TASK-010, TASK-OPT-01), `docs/STORY.md` (L02–L05), `docs/INTERACTION_SYSTEM.md` §4, §6, §7; контракты `00-contracts.md`.

**Предусловие:** M1 выполнен (ScriptRunner, LevelScene.loadLevel, OverlayScene/OverlayScreen, HintSystem, LEVELS).

## Global Constraints

- Правила `CLAUDE.md`: API Phaser/Vue — после сверки через Context7.
- Числа, раскладки и порядки — **точно** из `PUZZLE_SPECIFICATIONS.md`; не менять.
- Тексты — только ключами в `ru.json`; реплики — из `STORY.md`/`LEVEL_DESIGN.md`/`PUZZLE_SPECIFICATIONS.md`.
- Проигрыша нет; у P-04 и P-05 — кнопка «Сброс».
- Состояние недорешённой головоломки живёт, пока открыт уровень (закрытие экрана крестиком его не сбрасывает), но не сохраняется в `localStorage`.
- После решения каждой головоломки — шаг `{ checkpoint: true }`.
- Переходы между мирами на этом этапе — затемнение 0,4 с (кисть — в M4).
- Коммиты на русском, Conventional Commits, после каждой задачи.

## Review Focus

- P-02: вставка лампочки в закреплённый (1, 4) или уже занятый патрон — отказ, лампочка остаётся в инвентаре. Тест в Task 1.

- P-05: толчок ящика в сторону, где он сразу упирается, — стрелки нет, состояние не меняется. Тест в Task 4.
