# R2 «L01: пролог и Мастерская Улитки» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** L01 по `docs/SCRIPT.md` §4: расширенный диалог «Знакомство» (имя шпица, «почему ко мне», Улитка, просьба о помощи), выбор имени посреди диалога, намёки на Свету и террариум, второй экран «Мастерская Улитки» с брифингом и цель `L01_BRIEFING_DONE`; переход в L02 — только из мастерской.

**Architecture:** Всё data-driven: `L01.ts` (скрипт), `dialogs.json` + `ru.json` (тексты через конвейер из `SCRIPT.md`), карта мастерской — первая карта, собранная генератором R0 (`tools/maps/L01_workshop.ts`). Новый шаг скрипта `ifSpitzName` (реакция шпица на выбранное имя). Существующая карта `L01.json` и id экрана `apartment` **не переименовываются** (план называл `L01_flat.json`, но переименование ничего не даёт и ломает сохранения/тесты).

**Tech Stack:** TypeScript, Vitest, Vue 3, Phaser 4 (как в R0/R1).

**Spec:** `docs/SCRIPT.md` §4.1–§4.6; предыдущие планы R0, R1.

**Предусловие:** R0 и R1 выполнены, `npm test` зелёный.

## Global Constraints

- Правила `CLAUDE.md` (Context7 для API библиотек, коммиты на русском, миграций нет).
- Реплик в коде нет — только ключи; тексты — в `SCRIPT.md` → `npm run texts:build`.
- Графика — заглушки (`ensureTexture` по ключу текстуры из слоя `sprites`); реальные ассеты автор добавит позже, ключи перечислены в Task 6 и в `docs/ASSET_REQUIREMENTS.md`.
- До брифинга дверь мастерской не открывается; с Тиком, Таком и Маятником можно говорить, но обязательна только Улитка.

## Review Focus

- Любой порядок действий в мастерской: дверь до брифинга не ведёт в L02; брифинг нельзя «пройти дважды» с повторной выдачей флагов/чекпоинта. Тест в Task 5.
- Выбор имени стоит между двумя диалогами: загрузка сохранения после выбора не повторяет выбор (`spitzName` уже есть). Тест в Task 5 (логика шагов).
- Строка таблицы `SCRIPT.md` с `[ЗАПОЛНИТЬ … «…»]` (кавычки внутри пометки автора) остаётся полем автора, а не превращается в текст. Тест в Task 1.
- Все ключи, на которые ссылается L01 (диалоги, осмотры, подсказки), существуют в `ru.json`; все хотспоты скрипта есть на картах, точки подхода проходимы. Тест в Task 5.
