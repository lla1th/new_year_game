# GAMEPLAY — управление и игровой цикл

> APPROVED, кроме пунктов **[PROPOSED]**. Детали взаимодействий — `INTERACTION_SYSTEM.md`, интерфейс — `UI_UX.md`.

## 1. Игровой цикл

```
Вход в уровень → (заставка/диалог) → исследование сцены → сбор предметов →
→ решение головоломки → награда → переход к следующему уровню
```

Внутри уровня: осмотр объектов даёт подсказки, предметы открывают препятствия, головоломка завершает уровень.

## 2. Управление

| Действие | Компьютер | Телефон / планшет |
|---|---|---|
| Идти | ЛКМ по проходимой области | Тап по проходимой области |
| Взаимодействовать (взять / использовать / говорить) | ЛКМ по объекту | Тап по объекту |
| Осмотреть | ПКМ по объекту | Долгий тап (≥ 500 мс) **[PROPOSED: порог]** |
| Использовать предмет | Перетащить иконку из инвентаря на объект | То же, пальцем |
| Соединить предметы (только L07) | Перетащить один предмет на другой в инвентаре | То же |
| Показать все объекты | Пробел или кнопка 🔍 | Кнопка 🔍 |
| Подсказка | Кнопка-шпиц | Кнопка-шпиц |
| Пролистать диалог | ЛКМ / Пробел / Enter | Тап |
| Пауза / меню | Esc или ⚙ | ⚙ |

## 3. Перемещение Ксюши

- Point-and-click: клик по полу → Ксюша идёт в точку по кратчайшему пути внутри проходимой области.
- Клик по объекту → Ксюша идёт к его **точке подхода** (задаётся в Tiled), разворачивается к объекту и выполняет
  действие.
- Клик во время ходьбы меняет цель.
- Клик по непроходимой точке → Ксюша идёт к ближайшей проходимой точке **[PROPOSED]**.
- Скорость: **[PROPOSED]** 300 px/с в координатах 1920×1080.
- **Анимация «кукольная»**: одна поза на направление; при ходьбе — покачивание вверх-вниз (амплитуда 6 px,
  период 0,35 с) и лёгкий наклон ±3° **[PROPOSED: значения]**.
- Направления: 4 диагонали изометрии; рисуются 2 (вниз-вправо, вверх-вправо), левые — зеркалом.
- Позы: `idle`, `walk` (та же поза + покачивание), `use` (рука вперёд), `talk`, `hihik` (ладонь у рта, плечи трясутся).
- Шпиц следует за Ксюшей с задержкой и останавливается в 80 px позади неё **[PROPOSED]**. С L01 до L08 он всегда рядом,
  кроме кат-сцен.

## 4. Инвентарь

- Панель из **6 слотов** внизу экрана. Предметы переносятся между уровнями.
- Подобранный предмет занимает первый свободный слот. Больше 6 предметов одновременно по сценарию не бывает
  (максимум по сценарию — 4: мандарин и три лампочки в L02).
- **Использование**: перетащить предмет на объект сцены. Если взаимодействие предусмотрено — срабатывает;
  иначе Ксюша говорит случайную фразу из набора `common.wrongItem.*`, предмет возвращается в слот.
- **Осмотр предмета**: ПКМ / долгий тап по слоту — комментарий.
- **Комбинирование** — только ленточка + пряничная медаль в L07. Любая другая пара → «Не сочетается».
- Израсходованные предметы исчезают из инвентаря.
- **Детали Часов не лежат в инвентаре**: они попадают в индикатор Часов (HUD, 3 гнезда).

## 5. Диалоги

- Окно внизу экрана поверх сцены: портрет говорящего, имя, текст.
- Текст печатается по буквам. Клик во время печати показывает строку целиком, следующий клик — следующая реплика.
- В отдельных диалогах есть 2–3 варианта ответа Ксюши. Они меняют только следующую реплику-шутку, но не сюжет и не флаги.
- Во время диалога ходить и взаимодействовать нельзя.

## 6. Подсказки (совмещённая система)

- **Кнопка-шпиц**: каждое нажатие показывает следующую ступень подсказки к текущей цели:
  1. Намёк. 2. Где искать. 3. Прямой ответ.
  После 3-й ступени повторяется 3-я. Штрафов нет.
- **Автоподсказка**: если 90 с нет прогресса (новый флаг, подобранный предмет или решённая головоломка),
  шпиц сам произносит 1-ю ступень текущей подсказки. Сработает один раз на каждую ступень цели **[PROPOSED]**.
- Текущая цель определяется по флагам уровня (`INTERACTION_SYSTEM.md`, раздел «Цели»).
- До освобождения шпица в L01 кнопки ещё нет; автоподсказку произносит сама Ксюша мыслью.
- Тексты всех подсказок — `PUZZLE_SPECIFICATIONS.md` и `public/data/texts/ru.json`.

## 7. Ошибки и неудачи

Проигрыша нет. Неверное действие → шутка. Тупиковые состояния (P-04, P-05) → кнопка «Сброс».
Пятнашки (P-08) → кнопка «Перемешать заново» и автосборка через 5 минут.

## 8. Сохранение

- Автоматическое, в `localStorage` браузера.
- Контрольные точки: начало каждого уровня и момент решения каждой головоломки.
- «Продолжить» в главном меню — загрузка последней точки.
- После прохождения игры в меню открывается выбор любого уровня.
- Подробности — `TECHNICAL_SPECIFICATION.md`, раздел «Сохранение».
