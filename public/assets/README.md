# Ассеты игры

Все картинки и звуки перечислены в `public/data/assets.json` (ключ → путь). Чтобы подключить файл, положите его
по указанному пути — код менять не нужно. Пока файла нет, игра рисует заглушку (цветной прямоугольник с подписью ключа).

- Мир 1 (`img/world1/…`, пиксель-арт): фоны 480×270 PNG, спрайты персонажей высотой ≈ 48–56 px — в игре увеличиваются ×4
  без сглаживания.
- Миры 2, 3 и финал: фоны 1920×1080 WebP q85, спрайты высотой ≈ 360 px (PNG/WebP с альфой), ноги — нижний край по центру.
- Портреты: `img/portraits/<персонаж>_<стиль>.png` 256×256 (`public/data/characters.json`).
- Иконки предметов: `img/items/<ITEM_ID>.png` 128×128 (`public/data/items.json`).
- Курсоры: `img/ui/cursor_<default|hand|eye|gear|talk|exit>.png` 32×32.
- Звук: `audio/<music|sfx|ambient>/<id>.ogg` + `.m4a` (имя без расширения в манифесте). Для каждого файла — строка
  в `audio/CREDITS.md` (источник и лицензия).

## Анимации

Анимация называется **`<key записи>_<имя>`**. Где игра показывает картинку по ключу (позы Ксюши, шпиц, спрайты карт Tiled),
она сначала ищет анимацию с этим ключом и проигрывает её; если анимации нет — одиночную картинку; если нет и её — заглушку.

| Ключ анимации | Когда играет |
|---|---|
| `ksyusha_<w1\|w2\|w3>_dr_walk` | Ксюша идёт (вниз, влево — зеркалом). Есть кадры ходьбы → покачивание выключается |
| `ksyusha_<стиль>_ur_walk` | идёт вверх (необязательно; если нет — `dr_walk`) |
| `ksyusha_<стиль>_<d\|u\|l\|r>_walk` | идёт вниз / вверх / влево / вправо по экрану — 4 направления, приоритетнее `dr`/`ur`; нет `l` — зеркало `r` и наоборот (готово для `w1`: `img/characters/ksyusha_w1.png`) |
| `ksyusha_<стиль>_dr_idle`, `ur_idle`, `dr_use`, `dr_talk`, `dr_hihik` | вместо одноимённой картинки (например, «дыхание») |
| `spitz_<стиль>_walk` / `spitz_<стиль>_idle` | шпиц бежит следом / стоит |
| ключ текстуры спрайта карты (например, `l01b_tik`) | спрайт оживает, играет по кругу |

Три формата (запись в `public/data/assets.json`, `pixelArt: true` — для мира 1, увеличение ×4 без сглаживания):

**1. Aseprite** — проще всего: File → Export Sprite Sheet → Layout «Packed»; Borders: Trim Sprite/Cells, Padding 1;
Output: PNG + JSON Data, Meta: **Tags**, Item Filename — ровно `{frame}`. Тег = анимация, длительности кадров и
направление (forward / reverse / pingpong) берутся из файла; поле Repeat тега — сколько раз проиграть (пусто — по кругу).
Имена тегов — латиница, цифры, `_`.

```json
{ "key": "ksyusha_w1", "kind": "aseprite", "path": "img/characters/ksyusha_w1.png", "pixelArt": true,
  "levels": ["L01", "L02", "L03", "L08"] }
```
Рядом лежит `ksyusha_w1.json`; теги `dr_idle`, `dr_walk`, `ur_walk`… → анимации `ksyusha_w1_dr_walk` и т. д.

**2. Спрайт-лист** (сетка одинаковых кадров, номера слева направо, сверху вниз с 0):

```json
{ "key": "spitz_w2", "kind": "spritesheet", "path": "img/characters/spitz_w2.png", "frameWidth": 180, "frameHeight": 140,
  "levels": ["L04", "L05"],
  "anims": { "idle": { "frames": [0, 1, 2, 1], "frameRate": 4 },
             "walk": { "frames": { "start": 3, "end": 10 }, "frameRate": 12 } } }
```

**3. Атлас** (TexturePacker / Spine-экспорт кадров / любой «JSON Hash/Array»): `path` — PNG, JSON рядом с тем же именем
или в поле `data`; кадры — по именам:

```json
"anims": { "walk": { "frames": { "prefix": "walk_", "start": 1, "end": 8, "zeroPad": 2, "suffix": ".png" } } }
```

Параметры анимации: `frameRate` (кадров в секунду, по умолчанию 8), `repeat` (−1 — по кругу, по умолчанию; 0 — один раз),
`yoyo` (туда-обратно). Ошибки в записи видны сразу при запуске (`assets.json: …`), отсутствующие кадры — в консоли `[anims] …`.

Персонаж: ноги — нижний край кадра по центру, все кадры одного размера (в спрайт-листе) — иначе он будет «прыгать».

Фото реальных людей сюда не добавлять. Размеры и форматы — `docs/ASSET_REQUIREMENTS.md`.
