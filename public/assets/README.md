# Ассеты игры

Все картинки и звуки перечислены в `public/data/assets.json` (ключ → путь). Чтобы подключить файл, положите его
по указанному пути — код менять не нужно. Пока файла нет, игра рисует заглушку (цветной прямоугольник с подписью ключа).

- Мир 1 (`img/world1/…`, пиксель-арт): фоны 480×270 PNG, спрайты персонажей высотой ≈ 48–56 px — в игре увеличиваются ×4
  без сглаживания.
- Миры 2, 3 и финал: фоны 1920×1080 WebP q85, спрайты высотой ≈ 360 px (PNG/WebP с альфой), ноги — нижний край по центру.
- Портреты: `img/portraits/<персонаж>_<стиль>.png` 256×256 (`public/data/characters.json`).
- Иконки предметов: `img/items/<ITEM_ID>.png` 128×128 (`public/data/items.json`).
- Курсоры: `img/ui/cursor_<default|hand|eye|gear|talk|exit>.png` 32×32.
- Звук: `audio/<music|sfx|ambient>/<id>.ogg` + `.m4a` (имя без расширения в манифесте). Для каждого файла — строка
  в `audio/CREDITS.md` (источник и лицензия).

Фото реальных людей сюда не добавлять. Размеры и форматы — `docs/ASSET_REQUIREMENTS.md`.
